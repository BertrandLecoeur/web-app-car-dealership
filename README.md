# Car Dealership Web Application

Dynamic e-commerce website for car sales developed using PHP, HTML, CSS and JavaScript.

## Project Overview

This project simulates an online car dealership platform where users can:
- Browse vehicles by category
- Create an account
- Log in
- Add vehicles to a shopping cart
- Complete purchases
- Generate invoices
- Contact the company

---

## Features

- User authentication system
- Shopping cart management
- Vehicle catalog
- Dynamic product pages
- Payment form simulation
- Invoice generation
- Contact form
- Session management
- CSV-based data storage
